# Student Survey Analyzer

This is a simple Data Science practice project focused on analyzing and visualizing student survey data.

## Project goal
Perform basic exploratory data analysis (EDA) on a small survey dataset using Python.

## Project scope
- Load survey data from a CSV file
- Basic descriptive statistics
- Simple visualizations
- Practice Git/GitHub workflow (branch + PR)

## Technologies
- Python
- pandas
- matplotlib / seaborn

## Project status
Initial project setup for a course assignment.
